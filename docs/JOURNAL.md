## 4. Как редактировать и публиковать

1. Правишь `index.html` (контент + стили + скрипты — всё там).
2. **Если меняешь содержание резюме (опыт, навыки)** — продублируй правку в `resume-print.html`
   и перегенерируй PDF (см. ниже).
3. `git add` → `git commit` → `git push origin main`. Pages пересоберётся сам за ~1 мин.

### Перегенерация PDF
```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new \
  --no-pdf-header-footer \

  "file:///C:/Users/User/ClaudeC/STRES/resume-print.html"
```

## 5. Режим `?snap` и скриншоты (важные грабли)

- `index.html?snap` — отключает прелоадер и интро-анимации, **и принудительно показывает
  весь контент** (reveal-секции сразу видимы). Сделано специально для headless-скриншотов.
- **Грабли headless-скриншота Edge:**
  - `--screenshot` снимает **только видимый вьюпорт**, не всю страницу.
  - Высокое окно (`--window-size=1280,5000`) **ломает `vh`-секции**: hero = 100vh
    растягивается на всю высоту окна. Для полного снимка так нельзя.
  - `--print-to-pdf` рендерит страницу целиком, но **чтение PDF требует poppler
    (`pdftoppm`), которого в системе нет** → PDF не открыть как картинку.
  - **Рабочий приём для проверки конкретной секции:** собрать временный
    `dip/_preview.html` (имя с `_` → в .gitignore) с теми же стилями и кусочком разметки,
    снять его сверху окном нормальной высоты. Так проверены карточки сертификатов и лайтбокс.

## 7. Как добавить новый сертификат (рецепт)

1. Положи картинку в `dip/` с понятным именем (`cert-<что>-<кто>.jpg|png`).
2. В `index.html`, в блоке `<div class="certs__grid">`, скопируй существующую карточку
   `<button class="cert reveal-scale" ...>` и поправь: `data-src`, `data-caption`,
   `img src`/`alt`, `.cert__name`, `.cert__org`.
3. JS лайтбокса подхватит её автоматически (он собирает все `.cert`).
4. Проверь скриншотом (раздел 5), закоммить, запушь.

> Если картинка тяжёлая (PNG > 400 КБ) — пережми в JPG/WebP, чтобы страница не тормозила
> (`cert-zerocoder-claude.png` ~495 КБ — кандидат на оптимизацию).

## 9. Карьерные заметки: каких сертификатов не хватает и что быстро изучить

> Профиль: технарь онлайн-школ (GetCourse/Prodamus), реклама, партнёрки, чат-боты,
> Claude Code. Цель — усилить резюме под поиск работы.

### Сертификаты, которые стоит получить (быстро и в тему)
- **GetCourse** — официальное обучение/сертификация по платформе. Это якорный навык для
  вакансий «техспец онлайн-школы» — сертификат закрывает главный запрос работодателей.
- **Telegram-боты / автоворонки** — курс по конструктору (SaleBot, BotHelp, Senler).
  Подтверждает связку «боты + воронки + рассылки».
- ~~**Яндекс Директ**~~ — ✅ закрыто (сертификат «Барыга Трафика», 2024). Можно добить
  **официальной** сертификацией Яндекса (бесплатный экзамен) — даёт проверяемый значок от самого Яндекса.
- **Аналитика** — Яндекс Метрика (есть на сайте) + базовый GA/сквозная аналитика
  (Roistat). Работодатели любят «технаря, который считает деньги».
- **No-code / автоматизация** — Make (Integromat) или n8n. Логично ложится к Claude Code
  и «вижу всю систему».
- **AI для бизнеса** — раз уже есть «Вайб-кодинг на Claude Code», добей связку:
  промпт-инжиниринг, AI-ассистенты для поддержки/продаж.

### Что можно быстро изучить для лучшего поиска работы
- **CRM глубже** — amoCRM/Битрикс24 (воронки, интеграции, вебхуки). Частый пункт вакансий.
- **API и вебхуки** — связывать GetCourse ↔ боты ↔ CRM ↔ платёжки. Это «суперсила технаря».
- **Платёжные системы / эквайринг** — Prodamus, ЮKassa, CloudPayments: подключение, чеки, возвраты.
- **Базовый SQL / таблицы** — выгрузки, отчёты, дашборды (Google Sheets + скрипты).
- **Вёрстка лендингов** — Tilda/Craftum на уровне «соберу и подключу аналитику/оплату».
