Пример архитектуры: Lumos

Самый полный из моих примеров связанных агентов. Задеплоен на собственном VPS, есть живые пользователи. Ниже — как устроена система: оркестратор → агенты → интеграции → мониторинг. Скрины и промо-видео: sigurt33.github.io/lumos.

Как я подхожу к автоматизации

Система, а не скриптПроектирую иерархию: оркестратор → агенты → инструменты → интеграции. Роли и зоны ответственности разделены, компоненты переиспользуются.
Бизнес-задача → процессНачинаю с того, какой процесс дороже/медленнее всего в ручном режиме, и что именно можно исключить из ручной работы.
Надёжность после запускаФолбэк-цепочки, ретраи, гарды на плохой ответ модели, health-check, репликация и бэкапы, журналирование прогонов.
ИнтеграцииAPI, OAuth2, webhooks, структурированные данные, выгрузки/синхронизация между сервисами и БД.
ДокументированиеКаждый проект веду с журналом (DEVELOPMENT_LOG) и картой архитектуры (CLAUDE.md), чтобы система оставалась управляемой.
ИнструментыPython, JS/TS, Claude Code (вайбкодинг), LLM-роутинг (DeepSeek/YandexGPT/Claude/Ollama), SQLite/Postgres/Supabase, low-code при необходимости.
